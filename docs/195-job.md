### Kubernetes Jobs 

#### What is a Job?

- A Job creates Pods to execute a task and ensures successful completion.
- Used for finite, one-time workloads.
- Examples: Database migration, batch processing, data backup.

#### Execution hierarchy

```
Job → Pod → Container
```

#### Example YAML

```yaml
apiVersion: batch/v1
kind: Job
metadata:
  name: data-processing-job
spec:
  completions: 3          # Total successful completions required
  parallelism: 2          # Maximum concurrent Pods
  backoffLimit: 3         # Retry limit for failed Pods
  activeDeadlineSeconds: 300 # Maximum execution duration
  ttlSecondsAfterFinished: 100  # Delete Job 100 seconds after completion


  template:
    spec:
      containers:
        - name: processor
          image: busybox
          command: ["sh", "-c", "echo Processing data; sleep 10"]
      restartPolicy: Never  # Never | OnFailure
```

#### Useful commands

```powershell
kubectl apply -f job.yaml
kubectl get jobs
kubectl describe job data-processing-job
kubectl get pods
kubectl logs job/data-processing-job
kubectl delete job data-processing-job
```
